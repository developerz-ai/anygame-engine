# `.dz/`

The [developerz.ai](https://www.developerz.ai) maintainer bot's configuration for this repo. The platform owns the layout.

| Path | What |
|---|---|
| `maintainer/maintainer.yml` | the policy: what the bot triages, closes, reviews, merges, and must ask about |
| `briefs/` | what each `schedules:` checkup works from: `health.md` (broken links and an unindexed doc), `improve.md` (monthly accuracy upkeep) |
