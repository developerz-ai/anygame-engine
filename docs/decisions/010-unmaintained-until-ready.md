# 010 — No maintainer automation until the engine is ready

Status: accepted
Date: 2026-11-21

## Context
The project is at design stage, with no release to support.

## Decision
Do not enable the developerz.ai maintainer or add `.dz/` until the owner says so.

## Alternatives
- Enable it now: why not, automation would act on an unfinished design.
- Keep the repo private: why not, the project is open source from the start.

## Consequences
Issues and pull requests may go unanswered, and the README says so.
